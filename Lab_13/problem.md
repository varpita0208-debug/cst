# Readers’ Haven – Book Registration & Order Form

Source: [TASKS OF CST](../TASKS%20OF%20CST.pdf), PDF pages 20–21.

Create a bookstore registration and order form with action and target attributes. Include customer name, email, mobile, age, password, delivery date/time, a required favorite category dropdown (Fiction, Science, History, Children’s Books), book title, quantity with a minimum, payment method radio buttons, and multiple additional-service checkboxes. Include the hidden value "Readers Haven Book Order", an optional reference upload with accept, and a delivery address/special instructions textarea. Add suitable placeholders and button elements for Submit and Reset.

Open `html/index.html` in a browser.
