# My First HTML Webpage

Source: TASKS OF CST PDF, pages 2.

Create index.html with the title My First Web Page, an introduction, headings, paragraphs, a line break and horizontal rule. Demonstrate b, strong, i, em and u in one paragraph. Use superscript and subscript for a² + b² = c², (a + b)² = a² + 2ab + b², CO₂, C₆H₁₂O₆, x₁² + x₂² and CO₂²⁻.
