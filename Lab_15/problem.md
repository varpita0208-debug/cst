# Travel Agency Website Using Nested Frames

Source: TASKS OF CST slide deck, slides 24–25.

Create an "Explore the World – Travel Agency" website using an outer frameset with header (20%), main content (65%), and footer (15%). Split main content into navigation (25%), tourist destinations (45%), and travel packages (30%). Use separate pages for the header, navigation, home, destinations, packages, and footer. Name the frames and target the correct one from the navigation links. Demonstrate `scrolling`, `noresize`, `frameborder`, `marginwidth`, and `marginheight`. Show Manali, Goa, and Jaipur; Budget, Family, and Adventure packages; and footer contact details, email, and copyright.

Open `ExploreTheWorld/index.html` in a browser.
