# World Map Explorer

Source: [TASKS OF CST.pdf](../TASKS%20OF%20CST.pdf), page 12.

Create a webpage titled World Map Explorer using img, map and area tags. Make different countries clickable with circle, rect and poly regions. Give every area suitable coordinates, a distinct external information link, descriptive alt text and target="_blank".

Open `html/index.html`. The local SVG is a simplified illustrative map adapted from my existing CST exercise; highlighted regions match the clickable coordinates.
