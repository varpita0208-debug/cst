# Interactive Restaurant Menu Using Image Map

Source: [TASKS OF CST.pdf](../TASKS%20OF%20CST.pdf), pages 10-11.

Create an interactive restaurant menu with a food image and clickable regions. Each specific region must lead to a different webpage describing that item. Use appropriate alt text throughout.

| Item | Shape |
| --- | --- |
| Pizza | circle |
| Burger | circle |
| French Fries | rect |
| Menu Card | rect |
| Sandwich | poly |
| Cake Slice | poly |
| Remaining area | default |

Open `html/index.html`. The local menu illustration uses a fixed 800 x 500 size so its coordinates remain aligned; smaller screens can scroll it horizontally.
