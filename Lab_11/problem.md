# Nested Tables

Source: [TASKS OF CST](../TASKS%20OF%20CST.pdf), PDF pages 16–17.

Create four nested tables matching the reference image: Employee Salary Slip, Student Profile & Marks, Product Order Summary, and Hotel Booking. Place each detailed table inside its corresponding outer table cell. Use appropriate borders, alignment, rowspan, colspan, cellpadding, and cellspacing.

Open `html/index.html` in a browser.
