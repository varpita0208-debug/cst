# Online Course Registration

Source: [TASKS OF CST](../TASKS%20OF%20CST.pdf), PDF pages 18–19.

Create an online course registration form with action and target attributes. Include name, email, mobile, age, password, gender radio buttons, skills checkboxes, a required course dropdown, date of birth, preferred class time, a multiline address/additional information field, and a document/photo upload. Associate labels with controls using for/id. Add the hidden value "Online Course Registration". Use suitable input types, placeholders, values, and required attributes. Name, email, mobile, password, gender, and course must be mandatory. Use input elements for Submit and Reset.

Open `html/index.html` in a browser.
